# Swift for Rider, ReSharper and OmniMatrioshka

This is a ReSharper-based Swift engine and its corresponding language support.
Note that the Objective-C/Objective-C++ engine while a dependency for this engine 
is in a different repository and is a different plugin altogether.

The plugin and engine will hopefully be made available to CLion users
enabling true cross-platform development.
